# Inbox

Drop new sources here. Once ingested by Antigravity, they move to `01 - Raw Sources/`.

## Usage

1. Paste or clip a source here as a `.md` file.
2. Tell Antigravity: **"ingest [filename]"**
3. Antigravity will:
   - Read it, discuss key takeaways with you
   - Write wiki pages
   - Move this file to `01 - Raw Sources/`

## Tips

- Use **Obsidian Web Clipper** (browser extension) to convert web articles to markdown automatically.
- After clipping, hit your download-attachments hotkey to save images locally.
- You can drop PDFs, text files, or paste raw text — just save as `.md`.
